How to install it again later

  1. Select the block, Cmd C.
  2. Gmail → Settings → See all settings → General → Signature.
  3. Click into the box, Cmd A, then Cmd V.
  4. Scroll to the bottom, Save Changes.

Never rename or delete /sig/site.png, /sig/linkedin.png, /sig/github.png — Gmail caches them by URL. To change an icon, upload a new filename and re-paste the signature.
